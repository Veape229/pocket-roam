## 发布

把本目录的 `index.html`、`.nojekyll` 和本说明放进单独的 GitHub 仓库。
进入仓库 Settings → Pages，选择 Deploy from a branch、main 分支、根目录并保存。
GitHub 显示部署完成后，会提供实际公开地址。

页面无需构建、依赖或外部资源；图标和喵喵头像已内嵌，适用于项目子路径。

## 更新群信息

修改 `index.html` 中对应的群号和满员状态；若主要入口改变，同时修改复制按钮、脚本 `number`、页面描述及无障碍标签中的号码。
提交后 Pages 会重新部署。版本与页脚日期为手动维护。

请勿上传游戏源码、玩家存档、签名材料或 APK／EXE 到这个发布页仓库。
